The example limits coverage to 256 tile candidates per source, 8 concurrent mesh builds and a 32 MB / 256-tile offscreen mesh cache. Each worker also retains at most 16 MB / 32 completed projected meshes. These are not total memory or download limits. Collision-aware labels, elevations and feature picking remain deferred.
