The files carto-positron.json, carto-positron-v2.json, carto-positron-nolabels-v2.json,
carto-dark-matter-v2.json and carto-dark-matter-nolabels-v2.json in this directory are CARTO
basemap styles, as served from https://basemaps.cartocdn.com/gl/<style>/style.json. Their source
is https://github.com/CartoDB/basemap-styles. The `-v2` files are the styles as served on
2026-11-14 (tiles version 20261026-01, Protomaps basemap schema).

Only the styles are in this repository. The tiles, glyphs and sprites that the `-v2` styles point
at are not: the CARTO Basemaps terms (https://carto.com/legal/basemap-terms/) do not allow the
redistribution of map tiles or other map content. A local run downloads them into a directory
that git ignores (see `CARTO_V2_SCENES` in ../../scenes.ts).

Maps that use these styles must credit CARTO, OpenStreetMap and the tile schema, for example:
(c) CARTO (https://carto.com), (c) OpenStreetMap contributors
(https://www.openstreetmap.org/copyright).
